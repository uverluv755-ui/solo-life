# SOLO LIFE v0.10

毎日の行動が経験値になる、iPhone向けの人生RPG。

公開URL: https://uverluv755-ui.github.io/solo-life/

## v0.10のクエストとお知らせ

ホームの「今日のクエスト」には、端末の日付に合わせて2件の行動が自動で並びます。18時以降にその日のクエスト・集中セッションの達成がなく、タイマーも停止中なら、1分の緊急クエストが追加されます。各20 XPで、達成は履歴・能力値・週間ボスに反映されます。日替わりの行動は自作クエストの登録枠を使いません。

未達成の日は20時台に1回お知らせします。iPhoneはiOS 16.4以降でSafariの共有からアプリをホーム画面に追加し、アイコンから起動して「未達成の日のお知らせ」→「端末通知をオンにする」を選びます。オフも同じ場所です。オフラインで達成した場合は次のオンライン起動時に同期します。その間は通知が行き違うことがあります。

配信用のCloudflare Workerは `notifications/` にあります。[配信サーバーの設定](notifications/README.md)。

## v0.9.1の炎の演出

ステータスには黒い岩の上で揺れる青い炎を、ランク昇格には紫の炎を表示します。OSで視差効果を減らす設定にすると炎は静止します。画像はオフライン用のキャッシュに含まれます。

## v0.9のステータス画面

オリジナルの魔剣と月門を描いたプレイヤーカード、6種の能力紋章、経験値ゲージを追加。レベルアップでは剣の封印が開き、ランク昇格では王冠の紋章が現れます。魔剣の画像も初回のオンライン起動で端末に保存します。保存形式はv0.8と同じです。

## v0.8の目標別クエスト

初めて開いたら「目標から最初のクエストを選ぶ」をタップ。筋トレ・勉強・仕事・美容・健康の5分野から候補を絞れます。各分野に20 XPの小さな挑戦があります。「クエスト」タブからはいつでも同じ選択画面を開けます。

候補を選ぶと名前・能力・XPが入力されます。自由に編集して「クエストを追加」で登録し、実際に取り組んだら「ステータス」で達成を記録します。分野の切り替えは編集中の内容を保持します。保存にはv0.7と同じキーと形式（schemaVersion 3）を使います。

## 成長体験

- ステータス、6種類の能力値、デイリークエスト、集中タイマー、成長記録を維持し、iPhone向けの画面を刷新。
- 独自の光のシンボルと軌道を使ったデザイン。原作のキャラクター・画像・ロゴ・固有の台詞・名称・特徴的な画面は使用していません。
- レベルアップ時に光の演出と到達レベルを表示。ランク昇格時は専用の演出・メッセージに切り替わります。通常の達成時もXP・上昇能力・獲得称号を通知します。
- 独自ランクは灯火（Lv.1）、脈動（Lv.5）、共鳴（Lv.15）、飛躍（Lv.25）、極光（Lv.35）、星冠（Lv.50）。次のランクの必要XPと全ランクを確認できます。Lv.50以降もレベルは上がります。
- 累計100 XPごとに1レベル。**既存の200 XPはLv.3のまま**。ランクは累計XPから表示するだけで、過去の記録を書き換えたり追加XPを付与したりしません。
- レベルアップ表示は報酬獲得時のみ。再読み込み・バックアップ復元で過去の演出や報酬を繰り返しません。
- 集中タイマーの残り時間と経過リング、実行中のナビ表示、完了状態を追加。画面を閉じても期限から再開し、報酬は1回だけ付与します。通知・音はアプリ外では動作しません。
- セーフエリア、44px以上の主要タッチ領域、16pxの入力文字、キーボード操作、モーダルのフォーカス管理、OSの「視差効果を減らす」に対応。

## 継続して使える機能

- 1日1件以上のクエスト達成で連続日数を記録。今日の達成前は昨日までの連続日数を表示します。
- 月曜〜日曜の10クエストで週間ボス「継続の番人」を討伐。翌週は新しい挑戦になり、討伐記録は残ります。
- 5種類の実績・称号は一度獲得すると維持されます。
  - 初めての一歩：初めて経験値を獲得
  - 冒険者：累計500 XP
  - 継続の芽：3日連続達成
  - 七日の覚醒者：7日連続達成
  - ボス討伐者：週間ボスを1回討伐
- 曜日ごとの達成件数、週間の活動日数・クエスト数・獲得XPを表示。
- 集中セッションは従来どおり40 XPと知力+2を獲得。週間XPに含め、クエストの連続日数とボスの件数には含めません。過去の「集中ダンジョン」という履歴もそのまま残ります。
- iPhoneのセーフエリア、44pxの達成ボタン、ホーム画面用PNGアイコンに対応。

## iPhoneで使う

Safariで公開URLを開き、共有メニューから「ホーム画面に追加」できます。
オンラインで一度読み込むと、オフラインでも利用できます。
更新の準備ができると「最新版に更新」が表示されます。「記録」→「更新を確認」でも確認できます。
更新を適用する際は進捗と集中タイマーを保存して再読み込みします。入力途中のクエストは先に追加してください。

## 保存データの互換性

- **v0.4はv0.3のschemaVersion 3を維持**。v0.3の経験値・能力・履歴・日別集計・称号・ボス討伐・自作クエスト・達成状態・タイマーの保存形式を変更しません。
- 既存の `localStorage` キー `solo-life-v01` を継続使用します。経験値、能力値、クエスト、達成状態、履歴、集中タイマーを引き継ぎます。
- 旧データの初回移行前に、元のJSONを `solo-life-pre-v03` に退避します。
- v0.1/v0.2/初期v0.3の保存は、残っている履歴と最終達成日から日別の記録を復元します。旧版は履歴が最大100件で、クエストごとの日付も上書きされていたため、既に消えた過去の記録は復元できません。
- 新しい日別集計は最近100件の履歴とは別に保存します。クエスト削除や週替わりで過去の集計・獲得称号は消えません。
- 読み込めないデータや容量不足の場合、元の保存を初期データで上書きせず警告を表示します。
- 「記録」からJSONの書き出し・読み込みができます。旧形式のバックアップも読み込み可能です。
- データは端末・ブラウザ内の保存です。クラウド同期はありません。日付と週は端末のローカル時刻を使用します。

## 開発・検証

アプリ本体は静的HTML/CSS/JavaScriptで、ビルドや実行時依存はありません。

```sh
npm install
npm test
npx playwright install webkit
npm run test:browser
```

ブラウザテストはChromeとPlaywright WebKitを使用します（Chromeのインストールが必要）。
`BROWSER=webkit` または `BROWSER=chromium` で片方だけを実行できます。
既存v0.2（a200901）、v0.3（92839fb）、v0.7（e98dbea）の公開ファイルをGit履歴から読み込むため、履歴を含むチェックアウトで実行してください。

検証対象：旧版からの移行、v0.3のLv.3・200XPと全保存フィールドの維持、6ランクの境界、レベル・ランク演出、再読み込みでの演出再発防止、視差効果の軽減、二重受取防止、日付・週の切替、120日分の連続記録、称号の永続化、タイマー再開、バックアップ、保存破損・容量不足、320/375/390/430pxの表示、Service Worker更新、オフラインでの再読み込み。

v0.4検証結果：データ処理13テスト成功。ChromeとWebKitで上記ブラウザ検証が成功。200XPの移行検証はテスト用セーブで行い、利用者の端末内データは読み出していません。

WebKitのオフラインフラグには既知のテストエンジンの制限があるため、WebKitではローカルサーバーの通信を切断してキャッシュへのフォールバックを検証します。実機iPhoneのOS・Safariそのものを自動操作するテストではありません。

更新時は `sw.js` のキャッシュ名と、HTMLおよびService Workerに記載したアセットのバージョンを更新してください。
GitHub Pagesは既存の `main` ブランチのルートから公開します。
