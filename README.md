# SOLO LIFE v0.16

毎日の行動が経験値になる、iPhone向けの人生RPG。

公開URL: https://uverluv755-ui.github.io/solo-life/

## v0.16：身体づくりを中心にした「星鉄の鍛冶場」

ホームの先頭から筋トレを記録できる、オリジナルのダークファンタジーダッシュボードです。直近7日の実測日数・セット数、部位別マップ、装具、遠征ボスをまとめました。従来の175種の候補、登録クエスト、予定、タイマー、実測フォーム、目標ボス、難易度設定は維持しています。

- **セット記録**：日付、胸／背中／脚／肩／腕／体幹、種目、重量または自重、セットごとの重量・回数、疲労を保存。1種目1〜20セット、最大5000件。前回入力、セット複製、編集、削除に対応します。前回コピーは下書きで、保存するまで記録されません。
- **実測の振り返り**：「記録」の筋トレの軌跡に、部位別履歴、種目ごとの最高重量とその重量での回数、自重の最大回数、直近6記録日の小グラフ。比較キーは部位・正規化した種目名・自重／重量。ダンベルの片手／合計や器具の違いは種目名で区別します。実測を編集・削除すると自己ベストも再計算します。以前の単一数値記録は元のフォームに残し、不足するセットや部位を推測して変換しません。
- **装具と遠征**：記録した部位の装具が光ります。筋トレまたは休養を記録した日が1歩、同じ日の複数種目・編集・休養は重複加算なし。3／6／12日の称号・オーラ・冠、6歩ごとの遠征ボス討伐。期限・連続日数・体力の判定はありません。休養も1歩、休んでも減衰なし。獲得済みの歩みと称号は実測を訂正・削除しても保持します。
- **提案**：身体づくりの目標、当日の体調、今日・前日の部位と疲労から、休養または最近記録していない部位を案内します。疲れが強い記録では休養を提案。部位が異なれば回復済み、と判定する機能ではありません。元のクエスト提案も新しい記録を参照し、追加の筋トレや難易度上昇を控えます。筋トレ／休養の記録後は未達成のお知らせを抑制します。

### 実測とゲーム、保存について

記録の重量・回数・疲労・休養は**XPを付与しません**。従来のクエスト達成と100XP／レベル曲線はそのままです。遠征は新しい独立した装飾上の進捗で、従来の週間ボスや目標ボス・週間筋トレ報酬へ実測を二重計上しません。筋トレの実測値は自己申告であり、医学的な身体能力評価や健康効果の推定は行いません。休養と段階的な取り組み方の参考：[NHSの筋力運動](https://www.nhs.uk/live-well/exercise/strength-exercises/)。

保存キー `solo-life-v01` とschemaVersion 3を継続し、任意の `training: {version:1, goal, sessions, careDays, restDays}` を追加。旧セーブを読むだけでは追加せず、既存XP・レベル・クエスト・履歴・実測・難易度・進行中タイマーを保持します。JSONバックアップには全項目が含まれます。未知の拡張版・不正な数値は復元を拒否し、元の保存を保持。同時編集の衝突は上書きせず知らせ、保存失敗時は入力を保持します。v0.16の新記録を含むバックアップはv0.16以降で扱ってください。古いバージョンとの同時編集・逆方向の互換性は保証しません。

## v0.15：自分で選ぶ5段階の難易度

ホーム上部の「実力に合わせて難易度を選ぶ」、または今日のクエストの「難易度を選ぶ」から、筋トレ・歩行・勉強・仕事・生活をそれぞれE／D／C／B／Aに設定できます。新シリーズは各分野・各段階に3候補、計75件。従来100件を変更・削除せず、計175件から選べます。未設定の旧利用者には従来の候補を保ちます。初めて選ぶ際には利用日数やXPで上限を設けません。設定後は未設定の分野をEとして扱います。

| 分野 | Eの例 | B〜Aの例 |
| --- | --- | --- |
| 筋トレ | 支えを使ってもよいスクワット10回 | 自分に合う筋トレ30〜60分（準備・休憩込み） |
| 歩行 | 自分のペースで10分 | 平坦な道や屋内で30〜45分、分割可 |
| 勉強 | 学習・練習・読書15分 | 休憩を挟む60〜90分と振り返り |
| 仕事 | 重要タスクや成果物を15分進める | 60〜90分の集中と到達点確認 |
| 生活 | 片付け・家事計画・生活記録の見直し10分 | 30〜45分かけた整理・改善 |

新シリーズの達成後には「余裕／ちょうどよい／きつい」を任意で記録できます。ギルドは直近14日・同じ分野と段階の実績を使用し、直近3回が別々の3日に「余裕」なら1段階上、直近が「きつい」なら1段階下を提案します。「試す」を押すまで段階は変わりません。上の段階では改めて実績が必要です。体調が軽め・疲労・休養の日は引き上げを提案しません。

身体能力をゲームのレベル・重量・体重から推測しません。運動時間は目安で、短縮・分割・休養を選べます。筋トレを今日か前日に記録した場合、設定後の今日の候補とギルドの両方で筋トレを避けます。休養日は未達成の自動提案を止め、完了済みの記録や段階・XPは維持します。登録済みの自分のクエストは本人の判断で使えます。安全方針の参考：[NIDDKの身体活動ガイド](https://www.niddk.nih.gov/health-information/weight-management/healthy-eating-physical-activity-for-life/health-tips-for-adults)、[NHSの段階的な筋力運動](https://www.nhs.uk/live-well/exercise/how-to-improve-strength-flexibility/)。

### 報酬・保存・互換性

- 新シリーズは全段階20 XP。難易度を上げても既存の100 XP／レベル曲線を変更しません。
- 新シリーズの報酬は分野ごとに1日1回。難易度変更・別候補・予定・登録クエスト・削除再登録をまたいで同じ台帳を照合します。同じ既存カタログの行動も画面をまたいで重複受取できません。
- 既存XPの巻き戻しや履歴の書き換えはしません。変更前に受取済みの今日の候補は固定し、古い画面に残る異なる候補の受取は拒否します。新シリーズの候補を80 XPで登録しても実際の報酬は20 XPです。
- 感想・段階提案・設定保存ではXPもボスダメージも発生しません。集中タイマーは既存の独立した機能です。同じ実活動をタイマーとクエストの両方で申告しないでください。実活動を自動検知する機能や改造されたローカルデータの不正防止サーバーはありません。
- 保存キーとschemaVersion 3を維持。任意の `difficulty: {version:1, levels:…}` と日別 `catalogLog` を追加。旧セーブには読み込みだけで新項目を追加しません。不正な拡張データは復元拒否し、元の保存を維持します。新データはJSONバックアップに含まれます。
- PWAのキャッシュを更新し、新しい2スクリプトをオフライン対象に追加。旧100候補のキーは変更していません。新シリーズを使ったバックアップはv0.15以降で復元してください（旧版への逆方向の互換性は保証しません）。

### v0.15の検証

`npm test` で既存37件と新機能8件を実行。`npm run test:browser` はChrome／WebKitで旧版からの更新、新機能の設定・同時操作・感想・段階提案・バックアップ・容量不足・オフライン・320〜430pxおよび1024pxを検証します。WebKitのオフラインはテスト用サーバーの接続断で再現します。実機iPhoneのSafari／ホーム画面からの起動は別途実機確認が必要です。

## v0.14：ギルドと成長の5機能

優先順にギルドマスター、身体の実測記録、目標ボス、アバター進化、スキルツリーを実装しました。

- **ギルドマスター（無料・ルールベース／AI不使用）**：ホーム上部。100種類のカタログ、毎日の目標、直近7日の達成、累計の活動日数、当日の疲労申告から最大3件を提案します。自動で行動やXPを記録しません。「予定に追加」して実際に取り組んだあとに完了します。直近の筋トレ後は筋トレ候補を避け、疲れが強いときは短い非運動の候補、休養日は提案なし。疲労申告は当日だけ有効です。自由会話AI、外部AI API、課金はありません。
- **身体の実測記録**：「記録」で歩行時間（分）、運動回数（回）、トレーニング重量（kg）、体重（kg）を手入力。回数・重量には種目名を付けます。編集・削除、同じ項目と種目の前回測定日との比較、バックアップに対応。実測値からXP・能力値・ボスダメージは発生しません。推奨クエストの時間・回数を実測として転記しません。増減から健康効果を判定しません。最大5000件、超過時は保存を拒否して既存記録を保持します。
- **目標ボス**：「育成」で目標名、対象能力、3／7／14／30日の達成日数を選択。作成以降の対象クエスト・予定の達成で1日1ダメージ。集中・週間ボーナス・実測入力は対象外。連続日数や期限はなく、休養・休戦で進捗は減りません。休戦・再開、討伐の証に対応。最大100体を保持し、同時進行は3体まで。討伐自体で追加XPは付与しません。既存の週間ボスは変更せず残しています。
- **アバター進化**：「育成」で独自の姿と次の段階を表示。既存のLv.1／5／15／25を維持し、Lv.50「星冠の守護者」を追加。100XPごとに1レベルという従来の計算と既存ランクは変えません。
- **スキルツリー**：6能力に2段階ずつ、計12の紋章。ゲーム能力値15／30と前段階の習得で解放。消費ポイントや減衰はなく、紋章を習得すると専用候補を予定へ追加できます。習得自体でXPは増えず、身体能力の判定もしません。既存100種類の利用を制限しません。

休養日には未達成の緊急提案とアプリ内リマインダーを抑制します。既にオンにしている端末通知は、既存配信先にその日の抑制情報だけを同期します（既存APIのactiveDayを使用）。新たな身体記録・疲労の値・目標内容は送信しません。オフライン中は配信側に休養の選択が届かず通知が行き違うことがあります。

### v0.14の保存と互換性

`solo-life-v01` と `schemaVersion: 3` を維持し、任意の `journey` フィールド（version 1）だけ追加します。旧セーブの読み込み時にはこのフィールドすら自動追加しません。XP、能力値、クエスト、履歴、予定、日別の達成、タイマー、称号、週間ボス、未知の追加フィールドを保持します。新機能は既存の保存ロック・最新状態の再読込を通して保存し、容量不足では元の保存を維持します。バックアップには新機能も含まれます。不正な新機能データや将来版のjourneyを読み込んだ場合は、データを削除して起動し直さず、復元を拒否します。

身体記録は端末内のセーブに保存されます。端末間同期はありません。JSONバックアップには実測記録も含まれます。

## v0.13の日常クエストと成長記録

ホームの「毎日の目標」で筋トレ・歩行・睡眠・食事・勉強・仕事・美容・片付けを選べます。初期設定は「バランスよく取り組む」です。100種類の行動から、入門は毎日5件、累計7日達成後は6件を提案します。累計30日で「挑戦」も加わります。段階の判定には前日までにクエストを達成した日を数えます。18時以降の緊急クエストを含めると最大7件です。おすすめは各20 XP。おすすめを一つ達成すると当日の内容が確定し、その後の目標変更は翌日から反映します。

「クエスト」では分野別に候補を見て、自分の登録クエストにも追加できます。「記録」の7日・30日・90日は今日を含む期間の達成件数・活動日数・獲得XPと、直前の同期間との達成件数の差を表示します。歩行時間と筋トレ回数はv0.13のおすすめで達成を記録した内容を集計します。端末の歩数や実測時間は取得しません。

v0.13の検証はデータ処理・通知の27テストとChrome／WebKitのブラウザテストが成功。v0.12からの同日更新で受取済みの内容を保持すること、目標設定・段階移行・期間集計・同時受取・バックアップ・容量不足・オフライン動作を確認しました。画面幅320／375／390／430pxで確認済みです。iPhone実機でのホーム画面追加・起動は未検証です。

## ホームの「今日の予定」

用事を入力して「追加」を押すと、今日の予定になります。完了まで翌日にも表示され、完了すると20 XPが入ります。「日付・繰り返し・能力」で開始日や曜日を選ぶと、指定した日からその曜日にだけ表示されます。「筋力」を選んだ予定は週間筋トレにも数えられます。登録した予定はホームで編集・削除でき、過去の達成は記録に残ります。

## v0.11の筋トレクエスト

「今日のクエスト」の先頭に、器具なしでできる1分の筋トレが日替わりで登場します。達成すると20 XP・筋力＋1。月曜から日曜の間に3日筋トレしたら、「週間筋トレクエスト」から40 XP・筋力＋2をその週に1回受け取れます。登録した筋力クエストの達成も対象です。同じ日に何件達成しても、週間目標では1日と数えます。

## v0.10のクエストとお知らせ

ホームの「今日のクエスト」には、端末の日付に合わせて2件の行動が自動で並びます。18時以降にその日のクエスト・集中セッションの達成がなく、タイマーも停止中なら、1分の緊急クエストが追加されます。各20 XPで、達成は履歴・能力値・週間ボスに反映されます。日替わりの行動は自作クエストの登録枠を使いません。

未達成の日は20時台に1回お知らせします。iPhoneはiOS 16.4以降でSafariの共有からアプリをホーム画面に追加し、アイコンから起動して「未達成の日のお知らせ」→「端末通知をオンにする」を選びます。オフも同じ場所です。オフラインで達成した場合は次のオンライン起動時に同期します。その間は通知が行き違うことがあります。

配信用のCloudflare Workerは `notifications/` にあります。[配信サーバーの設定](notifications/README.md)。

## 成長体験

- ステータス、6種類の能力値、デイリークエスト、集中タイマー、成長記録を維持し、iPhone向けの画面を刷新。

- 5種類の実績・称号は一度獲得すると維持されます。
  - 初めての一歩：初めて経験値を獲得
  - 冒険者：累計500 XP
  - 継続の芽：3日連続達成
  - 七日の覚醒者：7日連続達成
  - ボス討伐者：週間ボスを1回討伐
- 曜日ごとの達成件数、週間の活動日数・クエスト数・獲得XPを表示。
- 集中セッションは従来どおり40 XPと知力+2を獲得。週間XPに含め、クエストの連続日数とボスの件数には含めません。過去の「集中ダンジョン」という履歴もそのまま残ります。
- iPhoneのセーフエリア、44pxの達成ボタン、ホーム画面用PNGアイコンに対応。

## iPhoneで使う

Safariで公開URLを開き、共有メニューから「ホーム画面に追加」できます。
オンラインで一度読み込むと、オフラインでも利用できます。
更新の準備ができると「最新版に更新」が表示されます。「記録」→「更新を確認」でも確認できます。
更新を適用する際は進捗と集中タイマーを保存して再読み込みします。入力途中のクエストは先に追加してください。

## 保存データの互換性

- **v0.4はv0.3のschemaVersion 3を維持**。v0.3の経験値・能力・履歴・日別集計・称号・ボス討伐・自作クエスト・達成状態・タイマーの保存形式を変更しません。
- 既存の `localStorage` キー `solo-life-v01` を継続使用します。経験値、能力値、クエスト、達成状態、履歴、集中タイマーを引き継ぎます。
- 旧データの初回移行前に、元のJSONを `solo-life-pre-v03` に退避します。
- v0.1/v0.2/初期v0.3の保存は、残っている履歴と最終達成日から日別の記録を復元します。旧版は履歴が最大100件で、クエストごとの日付も上書きされていたため、既に消えた過去の記録は復元できません。
- 新しい日別集計は最近100件の履歴とは別に保存します。クエスト削除や週替わりで過去の集計・獲得称号は消えません。
- 読み込めないデータや容量不足の場合、元の保存を初期データで上書きせず警告を表示します。
- 「記録」からJSONの書き出し・読み込みができます。旧形式のバックアップも読み込み可能です。
- データは端末・ブラウザ内の保存です。クラウド同期はありません。日付と週は端末のローカル時刻を使用します。

## 開発・検証

アプリ本体は静的HTML/CSS/JavaScriptで、ビルドや実行時依存はありません。

```sh
npm install
npm test
npx playwright install webkit
npm run test:browser
```

ブラウザテストはChromeとPlaywright WebKitを使用します（Chromeのインストールが必要）。
`BROWSER=webkit` または `BROWSER=chromium` で片方だけを実行できます。
既存v0.2（a200901）、v0.3（92839fb）、v0.7（e98dbea）の公開ファイルをGit履歴から読み込むため、履歴を含むチェックアウトで実行してください。

検証対象：旧版からの移行、v0.3のLv.3・200XPと全保存フィールドの維持、6ランクの境界、レベル・ランク演出、再読み込みでの演出再発防止、視差効果の軽減、二重受取防止、日付・週の切替、120日分の連続記録、称号の永続化、タイマー再開、バックアップ、保存破損・容量不足、320/375/390/430pxの表示、Service Worker更新、オフラインでの再読み込み。

v0.4検証結果：データ処理13テスト成功。ChromeとWebKitで上記ブラウザ検証が成功。200XPの移行検証はテスト用セーブで行い、利用者の端末内データは読み出していません。

WebKitのオフラインフラグには既知のテストエンジンの制限があるため、WebKitではローカルサーバーの通信を切断してキャッシュへのフォールバックを検証します。実機iPhoneのOS・Safariそのものを自動操作するテストではありません。

更新時は `sw.js` のキャッシュ名と、HTMLおよびService Workerに記載したアセットのバージョンを更新してください。
GitHub Pagesは既存の `main` ブランチのルートから公開します。
