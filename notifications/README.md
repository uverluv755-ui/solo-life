# 未達成リマインダーの配信

運用者がCloudflare Workersに一度配置します。利用者がCloudflareに登録する必要はありません。公開用の鍵だけをフロントエンドに置きます。

1. Cloudflareの無料アカウントでWranglerにログインし、このディレクトリで `npx wrangler deploy` を実行します。SQLite版Durable Objectsとアラームを使います。
2. 配置先URLの `/key` で公開鍵を確認します。秘密鍵は最初のアクセス時にサーバー内部で生成・保存されます。
3. リポジトリ直下の `push-config.json` に配置先の `service` と `publicKey` を設定してPagesを公開します。別の鍵に移行した端末は通知を一度オフにして再登録します。

一時アカウントから開始した場合は、Cloudflareの専用リンクで発行後60分以内に所有権を引き継いでください。引き継ぎ完了後は同じURLと鍵を使えます。期限が切れた場合は上記の手順で再配置します。引き継ぎリンクや管理トークンはGitHubに載せないでください。

通知先は端末ごとに分け、停止時に削除します。端末の時間帯で20時台に当日の活動を判定し、同じ日の連続送信を抑止します。受信者のクエスト名やXP履歴は端末内に残ります。OSの通知設定・集中モード・通信状態により表示が遅れることがあります。
